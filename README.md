# 🇹🇼 Taiwan Weather Tracker

A premium, visually stunning real-time weather tracking application mapped over Taiwan, built seamlessly with React, Leaflet, and the Central Weather Administration (CWA) Open Data API.

## 🌟 Key Features

- **Live Weather Updates:** Connects directly into the CWA API endpoint to fetch up-to-the-minute atmospheric conditions for various stations across Taiwan.
- **Sleek Glassmorphism UI:** Adopts a modern aesthetic with semi-transparent frosted glass elements floating on top of a dark-themed interactive map, providing a highly premium experience.
- **Responsive Map Integration:** Powered by `react-leaflet`, featuring custom SVG map markers with pulsing effects that align with the sophisticated design language.
- **No Heavy CSS Frameworks:** Built purely with Vanilla CSS for granular control over micro-interactions and smooth gradients, guaranteeing peak performance without bloat.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Install dependencies (if you haven't already):
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open up your browser and visit `http://localhost:5173` to experience the app.

## 🔧 Technology Stack

- **React + Vite:** For an ultra-fast development environment and optimized production builds.
- **react-leaflet:** To render clean, declarative map components.
- **Lucide React:** Providing sharp and consistent iconography.
- **Vanilla CSS:** Delivering raw, unobstructed styling freedom tailored for glassmorphism.

## 📡 API Usage

This project currently retrieves data from the CWA `O-A0001-001` (Station Observation) endpoint using an active authorization key.
